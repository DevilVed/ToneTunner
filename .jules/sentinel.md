
## 2024-05-31 - [CRITICAL] Fix Path Traversal in ZIP Extraction (Zip Slip)
**Vulnerability:** The `SetupActivity.java` file in Android extracted entries from a ZIP archive directly to the filesystem using `zipEntry.getName()` without validating the canonical path of the resulting file. This creates a "Zip Slip" vulnerability where a maliciously crafted ZIP file with `../` sequences in entry names could overwrite arbitrary files within the app's data directory.
**Learning:** `java.util.zip.ZipInputStream` does not inherently protect against directory traversal in ZIP entry names. When extracting ZIP files, especially those from external or unverified sources, the extracted file's canonical path must be explicitly validated against the target directory's canonical path. Additionally, explicit handling of directory entries (`zipEntry.isDirectory()`) and ensuring parent directories exist prior to file creation is necessary for robustness and security.
**Prevention:** Always use `File.getCanonicalPath()` to determine the absolute, normalized path of both the target extraction directory and the resulting file. Verify that the resulting file's path `startsWith(targetDirPath + File.separator)` before performing any file operations.
