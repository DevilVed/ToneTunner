## 2024-05-24 - [Zip Slip Path Traversal in Zip File Extraction]
**Vulnerability:** A classic Zip Slip vulnerability was found in `SetupActivity.zipExtract`. The code extracted entries directly from a ZipInputStream using `new File(targetDir, zipEntry.getName())` without verifying if the resulting canonical path remained inside the intended `targetDir`.
**Learning:** Even when extracting locally-provided files via an Intent, applications are vulnerable to Zip Slip if the zip archive is maliciously crafted with directory traversal characters (e.g., `../../evil`). Android's `File` API does not inherently prevent this.
**Prevention:** Always resolve the `getCanonicalPath()` of both the target directory and the destination file. Ensure the destination canonical path strictly `startsWith()` the target canonical path (appended with a `File.separator` to avoid partial-name bypasses). Additionally, manually create parent directories using `mkdirs()` before opening file streams.
