## 2024-05-18 - Prevent Zip Slip Vulnerability in ZIP Extraction
**Vulnerability:** Found a CRITICAL Zip Slip (path traversal) vulnerability in `SetupActivity.java` during ZIP extraction.
**Learning:** The application was using `ZipInputStream` to extract files without validating whether the `zipEntry.getName()` contained path traversal characters (like `../`). The UI updates were also incorrectly inside the `try` block, which could cause a hang if an exception was thrown. When fixing Zip Slip, it is crucial to handle `zipEntry.isDirectory()` separately to avoid `IOException` when attempting to open an `OutputStream` for a directory. Furthermore, when moving UI logic to a `finally` block for robustness, success-dependent logic (like showing the 'Start' button) must be guarded by a success flag to prevent exposing functionality when extraction fails.
**Prevention:** Always validate that the canonical path of the extracted file starts with the target directory's canonical path plus `File.separator`. Properly structure `try-catch-finally` blocks with success flags to ensure robust UI state management.
