## 2024-05-24 - [Zip Slip Path Traversal in Zip File Extraction]
**Vulnerability:** A classic Zip Slip vulnerability was found in `SetupActivity.zipExtract`. The code extracted entries directly from a ZipInputStream using `new File(targetDir, zipEntry.getName())` without verifying if the resulting canonical path remained inside the intended `targetDir`. It also did not handle zip directory entries natively.
**Learning:** Even when extracting locally-provided files via an Intent, applications are vulnerable to Zip Slip if the zip archive is maliciously crafted with directory traversal characters (e.g., `../../evil`). Android's `File` API does not inherently prevent this. When fixing Zip Slip, ensure that thrown exceptions (like `SecurityException`) are caught properly and the UI state is recovered via a `finally` block to avoid hanging the app.
**Prevention:** Always resolve the `getCanonicalPath()` of both the target directory and the destination file. Ensure the destination canonical path strictly `startsWith()` the target canonical path (appended with a `File.separator` to avoid partial-name bypasses). Additionally, handle directory entries explicitly via `zipEntry.isDirectory()` and manually create parent directories using `mkdirs()` before opening file streams, verifying their success.
