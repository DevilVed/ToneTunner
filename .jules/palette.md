## 2026-01-26 - Expanding Touch Targets via Parent Containers
**Learning:** Legacy layouts often place a `CheckBox` next to a `TextView` label within a non-interactive `LinearLayout`. This restricts the touch target to just the small checkbox (often 24-32dp), making it difficult for users to interact with, especially while mobile or with motor impairments.
**Action:** Convert the parent container (e.g., `LinearLayout`) into an interactive element by adding `android:clickable="true"`, `android:focusable="true"`, and `android:background="?android:attr/selectableItemBackground"`. Then, in Java/Kotlin, attach an `OnClickListener` to the container that delegates the action to the child element (e.g., `checkBox.performClick()`). This expands the effective touch target to the full width of the row without changing the visual design significantly.
