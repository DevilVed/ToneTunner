## 2024-07-14 - Expanding Checkbox Touch Targets via Parent Containers
**Learning:** Expanding touch targets for Android checkboxes (e.g. settings toggles) requires a multi-step approach when the layout uses a generic container like `LinearLayout`. Simply wrapping them and adding click listeners isn't enough; the child CheckBox itself must explicitly be set to `clickable="false"` and `focusable="false"` to prevent focus/accessibility tools from targeting the tiny checkbox directly, and to prevent double-click events when programmatically routing `parent.setOnClickListener(v -> checkbox.performClick());`.
**Action:** When asked to improve tap targets for toggles, wrap them in a clickable, focusable parent with a selectable background (`?attr/selectableItemBackground`), but ensure the internal toggles have their innate click/focus states disabled to prevent conflicting accessibility interactions.
